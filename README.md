# DNS Cache on a Custom Hash Table

Учебный проект на Python: кэш DNS-записей с собственной реализацией хеш-таблицы, TTL и сохранением данных в CSV.

## Что реализовано

- собственная `HashTable` с separate chaining для обработки коллизий;
- динамический resize при превышении load factor;
- CRUD-операции для DNS-записей по ключу `domain + record_type`;
- TTL и автоматическое удаление устаревших записей;
- подсчёт записей по типам;
- сохранение/загрузка CSV;
- генератор тестового набора до **1 000 000 записей**;
- автоматические тесты на `unittest`.

## Зачем этот проект

Проект сделан в рамках курса по алгоритмам и структурам данных. Основная цель - разобраться, как устроена хеш-таблица изнутри, как обрабатываются коллизии и как сохранять корректность данных при resize.

## Структура

```text
hash_table.py       # собственная хеш-таблица
dns_record.py       # модель DNS-записи
dns_cache.py        # бизнес-логика кэша
type_counter.py     # счётчик типов записей
generate_data.py    # генерация большого набора данных
main.py             # консольный интерфейс
tests/              # тесты
```

## Запуск

```bash
python main.py
```

Для генерации миллиона записей:

```bash
python generate_data.py
```

## Тесты

```bash
python -m unittest discover -s tests -v
```

В подготовленной версии проходит **11/11 тестов**.
